# My Home Bookkeeping Website

Temporary static website for the Android application My Home Bookkeeping.

Domain: `mhbk.app`

## GitHub Pages

This repository is intended to be published with GitHub Pages from the `main` branch and the repository root.

## Technical Notes

- Static HTML and CSS only
- No server-side code
- No PHP
- No database
- No analytics
- No cookies
- No external trackers
- No third-party JavaScript libraries
